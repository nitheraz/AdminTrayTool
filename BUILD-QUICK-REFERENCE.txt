❓ FAQ
─────────────────────────────────────────────────────────────────────────

Q: How long does build take?
A: ~30-60 seconds for basic build, longer if GAM7 is included (~5MB per sec)

Q: Can I build on non-admin machine?
A: No, MSI build requires admin to create installer engine

Q: Can I ship MSI without GAM7?
A: Yes, build will skip GAM7 if folder missing or deleted before build

Q: How big is the MSI?
A: ~10-50MB without GAM7, ~400MB+ with GAM7 included

Q: Can I update MSI after release?
A: Yes, increment version and rebuild. Old version uninstalls cleanly.

Q: Is there auto-update?
A: Not built-in, but MSI supports side-by-side installs with versioning
