# About & Versioning

## Versioning

AdminTrayTool follows [Semantic Versioning](https://semver.org/):

```text
MAJOR.MINOR.PATCH
```

### MAJOR

Breaking changes that may require configuration changes or other user action.

### MINOR

New functionality that maintains backward compatibility.

### PATCH

Bug fixes, maintenance updates, and other changes that do not introduce new functionality.

## GAM7

AdminTrayTool uses [GAM7](https://github.com/GAM-team/GAM) for Google Workspace administration functionality.

GAM7 is bundled with the AdminTrayTool installer.

The AdminTrayTool project does not include an organization's authenticated GAM7 OAuth tokens or other user-specific authentication credentials.
