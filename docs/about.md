# About & Versioning

AdminTrayTool follows [Semantic Versioning](https://semver.org/) (`MAJOR.MINOR.PATCH`):

- **MAJOR** — breaking changes
- **MINOR** — new features, backward compatible
- **PATCH** — bug fixes only

## Release Notes

See the [GitHub Releases page](https://github.com/nitheraz/AdminTrayTool/releases) for the full changelog and downloadable installers for every version.
